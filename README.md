# p2proxy：A 通过 B 的网络上网（点对点，无需服务器）

一个 Windows 桌面程序，两种角色：出口电脑（B）当**服务端**，其他电脑（A）当**客户端**，客户端通过服务端的网络上网。两台电脑之间直接连接（UDP 打洞 + QUIC 加密隧道），不经过任何中转服务器；客户端输入密钥即可连接，并自动生成 Clash 订阅地址。

源码在 [`cpp/`](cpp/)，下载、使用、编译和发布说明见 [cpp/README.md](cpp/README.md)。

旧的 Go 版（v1.x）已不再维护，源码保留在 Git 历史和 `v1.0.2` 标签里。
